# Build Tecnorampa Pro-Store

Follow these steps to install dependencies, verify TypeScript typing, and build the Next.js production bundle.

## 1. Install Dependencies
```bash
npm install --no-audit --no-fund
```

## 2. Typecheck Code
Run TypeScript static check to ensure no type mismatch errors:
```bash
npm run typecheck
```

## 3. Build Web Application
Compile and generate the optimized production assets:
```bash
npm run build
```
