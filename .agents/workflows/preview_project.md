# Preview Tecnorampa Pro-Store

Follow these steps to launch the local Next.js development server with Turbopack.

## 1. Start Development Server
```bash
npm run dev
```

The application will be accessible at:
- **Local**: `http://localhost:9002`

## 2. Verify Storefront
Open `http://localhost:9002` in your browser to test navigation, catalog filters, cart, and the AI logistics assistant.
